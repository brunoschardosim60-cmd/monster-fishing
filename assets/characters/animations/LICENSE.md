# Animations — Quaternius Universal Animation Library (CC0)

`ual_humanoid.res` holds clips from **Universal Animation Library** and **Universal Animation Library 2** by
Quaternius (https://quaternius.com), released under **CC0 1.0 Universal (public domain)**:
https://creativecommons.org/publicdomain/zero/1.0/

The clips were retargeted onto the game's 17-bone survivalist rig by `scripts/pipeline/bake_ual_animations.gd`
(source files: `Unreal-Godot/UAL1.glb` and `UAL2.glb`, the versions without root motion). Each clip keeps its source
name in its `source` metadata. The original GLB files are not stored in this repository.
